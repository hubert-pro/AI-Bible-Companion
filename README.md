# AI-Bible-Companion
This is a sophisticated and feature-rich web application designed to be a comprehensive digital tool for exploring and understanding the Christian Bible. It's more than just a simple chatbot; it's a multi-faceted platform that leverages the power of the Gemini API to provide a deeply interactive and engaging user experience. The application is built with a clean, modern, and responsive interface using React and Tailwind CSS, featuring both light and dark themes to ensure user comfort.
The application is structured around four main features, accessible through a clear tab-based navigation:
Chat Companion: This is the core conversational feature. It provides a direct line to an AI assistant that has been given a specific persona: a patient, knowledgeable, and encouraging Christian guide. Users can ask complex theological questions, request explanations of parables, or simply have a conversation about faith. The AI's responses are streamed in real-time, creating a fluid and natural chat experience. This section also prominently features a "Verse of the Day" to provide daily inspiration.
Scripture Search: A powerful search engine for the Bible. Users can find scriptures in two ways:
Direct Search: By typing in a topic (e.g., "forgiveness," "hope") or a specific verse reference (e.g., "Psalm 23"). The AI returns a list of relevant verses, each complete with the full text and a concise explanation of its context and meaning.
Browse: For a more traditional study method, users can navigate the entire Bible, selecting a book and then a chapter to read its contents.
Image Generator: A unique and creative tool that brings the Bible to life visually. Users can describe any biblical scene (e.g., "Moses parting the Red Sea," "The Last Supper"), and the AI will generate a beautiful, artist-rendered image of that scene. Crucially, it also provides the primary scripture reference for the scene and a paragraph explaining its significance, adding valuable context to the visual. This feature also includes text-to-speech narration and a built-in sharing function.
Bookmarks: This feature provides a personalized space for users. Any verse discovered through the Scripture Search can be bookmarked with a single click. These saved verses are collected in the Bookmarks tab, allowing users to easily revisit, study, and reflect on passages that are meaningful to them.
Under the hood, the application intelligently uses different Gemini models for different tasks: gemini-2.5-flash for the chat and for extracting structured data, gemini-2.5-pro for the more complex search queries, and gemini-2.5-flash-image for the stunning image generation. The entire experience is designed to be accessible, intuitive, and spiritually enriching for users at any stage of their faith journey.
